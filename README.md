## Projects

### [DPI Analyzer — Real-Time Deep Packet Inspection System](https://github.com/sumanth2005-hub/dpi-analyzer)
`Java 17` `Spring Boot 3.3` `pcap4j` `MySQL` `Spring Data JPA` `SSE`

- Real-time packet capture engine inspecting live traffic across 9+ protocols (HTTP, HTTPS, DNS, SSH, MySQL)
- SSE-based streaming pipeline pushing live events to browser dashboard, sub-second latency, no client polling
- Bounded in-memory ring buffer (LinkedBlockingDeque) for high-throughput streams without memory overflow
- Spring Data JPA + MySQL for persistent traffic logging and historical query support
- Dark-themed monitoring dashboard with live charts and protocol-level breakdown

- OTP-based citizen auth via Fast2SMS with secure session handling and multi-step registration
- Admin analytics dashboard for scheme usage, registration stats, and voice-assisted accessibility
- Dual-database architecture (MongoDB for documents, SQLite for relational data), clean service separation
